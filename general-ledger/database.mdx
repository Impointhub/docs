## DB-1 General Ledger Filter

| Column Frontend | Type | Rules | Sample Data | Tujuan | Notes |
|---|---|---|---|---|---|
| Date From | DATE | Wajib diisi. Format dd-mm-yyyy. Kosong saat halaman dibuka. | 01-08-2026 | Batas awal periode ledger | Dipakai 24.1S1, 24.2S1, 24.2F1, 24.3S1. Juga menjadi batas perhitungan Opening Balance. |
| Date To | DATE | Wajib diisi. Format dd-mm-yyyy. Kosong saat halaman dibuka. | 31-08-2026 | Batas akhir periode ledger | Dipakai 24.1S1, 24.2S1, 24.2F1, 24.3S1. |
| Account | VARCHAR(100) | Wajib dipilih. Daftar hanya berisi akun yang boleh diakses user (DB-4). Tampil "kode - nama". Satu akun per tampilan. | 10101 - Cash on hand | Memilih akun CoA yang ledger-nya ditampilkan | Jika user tidak punya akses akun, daftar kosong (24.1F3, 24.2F1). |
| Export to Excel (button) | - | Nonaktif sampai Date From, Date To, dan Account terisi. Aktif setelah ketiganya terisi. | - | Mengunduh ledger sesuai filter | 24.3S1. (aktif), 24.3F1 (nonaktif). |

## DB-2 General Ledger Data

| Column Frontend | Type | Rules | Sample Data | Tujuan | Notes |
|---|---|---|---|---|---|
| Date | DATE | Autofill dari form reference. Hanya transaksi akun terpilih dengan tanggal dalam Date From s/d Date To, urut tanggal. | 03-08-2026 | Tanggal transaksi terjadi | |
| Reference | VARCHAR(20) | Autofill dari form reference. | CI/2608/006 | Nomor dokumen sumber, untuk ditelusuri | Prefix CI/CO untuk Cash, BI/BO untuk Bank. |
| Master | VARCHAR(100) | Autofill dari form reference. | Budi Santoso | Customer / supplier / pihak pada transaksi | Diperbesar dari VARCHAR(10) karena mockup menampilkan nama. |
| CoA (counter account) | VARCHAR(100) | Autofill dari form reference. Akun lawan dari akun terpilih, format "kode - nama". Tampil satu baris dengan transaksi. | 40201 - Service Revenue | User langsung tahu lawan akun transaksi (ADR001) | Kolom baru, sebelumnya tidak ada di database. |
| Description | VARCHAR(255) | Autofill dari form reference. | Service payment | Keterangan transaksi | |
| Debit | DECIMAL(18,2) | Autofill dari form reference. Tampil "-" jika 0. | 26250000.00 | Nilai debit transaksi | |
| Credit | DECIMAL(18,2) | Autofill dari form reference. Tampil "-" jika 0. | 0.00 | Nilai kredit transaksi | |
| Balance | DECIMAL(18,2) | Dihitung otomatis = Balance baris sebelumnya + Debit - Credit. Baris pertama memakai Opening Balance. | 123500000.00 | Saldo berjalan setelah transaksi ini | |
| Opening Balance | DECIMAL(18,2) | Dihitung otomatis, bukan input = total (Debit - Credit) akun terpilih untuk semua transaksi sebelum Date From. | 100500000.00 | Saldo awal periode | Tampil di baris pertama tabel. |
| Total Debit / Total Credit | DECIMAL(18,2) | Dihitung otomatis = jumlah Debit dan jumlah Credit pada periode. | 167250000.00 / 24000000.00 | Total pergerakan periode | |
| Ending Balance | DECIMAL(18,2) | Dihitung otomatis = Opening Balance + Total Debit - Total Credit. Sama dengan Balance baris terakhir. | 243750000.00 | Saldo akhir periode | |

## DB-4 User Account Access (role permission CoA)

| Column Frontend | Type | Rules | Sample Data | Tujuan | Notes |
|---|---|---|---|---|---|
| User | VARCHAR(100) | Wajib. | Aini | Pemilik hak akses | |
| Permission Read General Ledger | BOOLEAN | Yes / No. No: halaman Access Denied (24.1F2). | Yes | Syarat membuka /accounting/general-ledger | Belum login diarahkan ke halaman login (24.1F1), berdasarkan sesi, bukan tabel ini. |
| Accessible Accounts | LIST of Account Code | Hanya akun ini yang muncul di dropdown Account dan datanya tampil. Kosong: tampil pesan "No account is assigned to you..." (24.1F3, 24.2F1). | 10101, 10205 | Menjaga kerahasiaan data per akun (ADR002) | |

## DB-5 Export & System Message

| Column Frontend | Type | Rules | Sample Data | Tujuan | Notes |
|---|---|---|---|---|---|
| Export File Name | VARCHAR(100) | `general-ledger_{Account Code}_{Date From}_{Date To}.xlsx`, tanggal format yyyy-mm-dd. | general-ledger_10101_2026-08-01_2026-08-31.xlsx | Nama file hasil export | 24.3S1. |
| Export Content | - | Satu sheet "General Ledger": Opening Balance, baris transaksi, Ending Balance sesuai filter. | - | Isi file export | 24.3S1. |
| Notification Export | VARCHAR(100) | Tampil setelah file berhasil dibuat. Tanpa kode scenario. | Successfully export general ledger | Konfirmasi export berhasil | 24.3S1. |
| Message - Filter Belum Lengkap | VARCHAR(150) | Tampil selama Date From, Date To, atau Account belum terisi. | Select Date From, Date To, and an account to display the general ledger. | Arahan untuk user | 24.1S1, 24.3F1 |
| Message - Tidak Ada Akses Akun | VARCHAR(150) | Tampil jika Accessible Accounts kosong. | No account is assigned to you. Ask your administrator for account access. | Menjelaskan alasan dropdown kosong | 24.1F3, 24.2F1 |
| Message - Tidak Ada Transaksi | VARCHAR(100) | Tampil jika filter lengkap tetapi tidak ada transaksi pada periode. | No transactions in this date range. | Menjelaskan tabel kosong | |
